ABOUT THIS PROJECT

Student Performance Prediction System

Project Overview

This Data Mining mini project uses a Decision Tree Classification algorithm to predict whether a student is likely to pass or fail.

Input Features

The model uses nine features: Age, Study Time, Past Failures, Absences, Travel Time, Family Support, Paid Extra Classes, Higher Education Interest and Internet Access.

Target Definition

Students with final grade G3 greater than or equal to 10 are classified as Pass. Students with G3 below 10 are classified as Fail.

The final grade is used only to create the target label and is not given as a prediction input.
